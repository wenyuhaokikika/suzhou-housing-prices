数据来源说明

本看板如何取数、为何出现「示意」标签、如何尝试实盘爬取

一句话结论

当前库内主体为 本地示意数据（source=demo）： 小区名为苏州市辖区真实可识别小区/楼盘名， 价格与成交为按近年公开市场常见区间合成的近三年趋势， 不是链家/贝壳/安居客等站点的实时实爬结果。

原因：在本环境对贝壳（ke.com / lianjia.com）、安居客等发起请求时，多次返回验证码/反爬页或连接失败， 无法稳定解析列表；好好选房等站点路径亦不可用。为不影响分析与看板演示，使用了标注清晰的 demo 灌数。

示意数据如何生成

  • 目录：scrapers/suzhou_communities.py（姑苏/虎丘/吴中/相城/吴江/工业园区）
  • 灌数：python -m scrapers.run --region all --demo-only
  • 字段：source=demo，source_url 为空（不再生成会 404 的假链接）
  • 价格：以各小区别名均价为基准，叠加近三年温和波动与噪声，生成挂牌、成交与月度快照

如何尝试实盘爬取

cd /workspace/housing-prices && source .venv/bin/activate
python -m scrapers.run --region wuzhong --source beike --max-pages 2
python -m scrapers.run --region sip --source anjuke --max-pages 2

实盘成功写入的行会带有真实 source（如 beike）与可访问的 source_url，详情表中会显示为可点击链接。 若仍被反爬，请降低频率、更换网络，或改用官方/合规数据源；切勿绕过登录墙或验证码。

关于「好好选房」公众号 / 小程序

「好好选房Pro」（微信号 haohaoxuanfang）与官网 amillion.cn 主要为微信小程序/公众号形态：公开网页几乎只有导流落地页， 没有可稳定爬取的苏州房源 HTML 列表或开放 API。

本仓库已实现 haohaoxuanfang 爬虫探测；本环境实测为 skipped（小程序落地 / 无列表）。若要从公众号拉数，需要你在 已登录微信的浏览器或手机中打开小程序/文章，协助抓包导出 JSON， 或提供可访问的分享链接后再接入导入器。

关于「2020 年以后」筛选

示意库已补充大量 2020–2026 新房与近年交付转二手小区。 服务端示例：/regions/wuzhong?year_min=2020、 /regions/wuzhong?market=ershou&year_min=2020。
